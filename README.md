# 🗺️ HTML Path

Welcome to the official roadmap for **HTML Path**. This is a game about learning how to build things for the web, starting from the absolute basics and moving all the way up to complex structures. 

There are 5 different maps you can choose to play through:

## 🗺️ Map 1: Quiz Path
Answer questions, protect your hearts, and collect stars across 5 levels.

## 🗺️ Map 2: Construction Site
Write real HTML with Tab autocomplete features, starting with a friendly tutorial.

## 🗺️ Map 3: Advanced Construction
Tackle five tougher builds to master tables, forms, media, and semantic structures.

## 🗺️ Map 4: Free Build
An open sandbox with no rules where you can toggle style sets, remix builds, and copy code.

## 🗺️ Map 5: Complex HTML
The final locked challenge area for advanced development once the other building maps are complete.
